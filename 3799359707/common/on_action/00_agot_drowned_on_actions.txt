# AGOT: Magic of Westeros v2 - Drowned God
# IMPORTANT (corrected after testing): only the on_action's `events` list
# merges across mod files - a bare `effect = {}` block does NOT merge, the
# last-loaded file's effect silently replaces every other mod's effect for
# that on_action (confirmed via error.log: "There is more than one
# 'effect' defined using most recent"). Since our mod loads after AGOT,
# an `effect = {}` block here would have silently discarded AGOT's entire
# on_natural_death_second_chance logic (its dying-king story branch AND
# the vanilla flag-setting/death_management.9998/9999 chain) for every
# character in the game, not just Drowned God perk holders. Fix: hook in
# via the merging `events` list instead, pointing at a tiny hidden
# wrapper event that does our own has_perk check.

on_natural_death_second_chance = {
	events = {
		agot_drowned.0005
	}
}
